# AIMST RMC Website Redesign — Front-end Prototype

## Launch locally
1. Extract the ZIP.
2. Double-click `index.html`.

For best results, use a local web server:

### Python
```bash
python -m http.server 8080
```

Then open:
http://localhost:8080

## Files
- `index.html` — page structure and content
- `styles.css` — design and responsive layout
- `script.js` — counters, animations, grant filters, mobile navigation and Ask RMC interaction

## Notes
This is a front-end prototype. Replace sample metrics, grant calls, links and centre names with verified institutional data before production deployment.

For production deployment, connect the site to AIMST's existing CMS/backend and authentication system rather than using the placeholder `My RMC` link.
