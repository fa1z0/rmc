# AIMST RMC Website — Start Here

This is the **Stage 1 clean/ordered version**. The visual design and website features are intentionally unchanged. The purpose of this version is to make the existing package understandable before adding a visual/AI editor.

## The 3 files that control the public website

1. **index.html** — what appears on the page (text, headings, cards, buttons, sections).
2. **styles.css** — how those things look (colour, spacing, sizes, layout, mobile styles).
3. **script.js** — what moves, filters, opens, animates or reacts to clicks.

All three now use the **same section number**. Search the same code in each file.

Example: search **RMC-06** to find Research Explorer in HTML, CSS and JavaScript.

## How script.js is labelled

- **[EDITABLE CONTENT]** — data you can normally change safely, such as Research Explorer categories or map partner records.
- **[ELEMENTS]** — connections to HTML elements.
- **[FUNCTIONS]** — working code; usually leave this alone unless changing behaviour.
- **[EVENTS]** — click/submit/scroll actions.

## Important

Do **not** start the new visual editor/AI editing system from this Stage 1 package yet. First use this cleaned version as the stable baseline. The next stage can then convert one numbered section at a time into a user-friendly control panel.
